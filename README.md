# 📅 Daily Practice System

The repository follows a simple practice system:

### 🗓️ Daily Target

**15 Problems per topic**

Recommended approach:

```text
Problems 01–05
     ↓
Learn the concept
     ↓
Problems 06–10
     ↓
Apply the concept
     ↓
Problems 11–15
     ↓
Challenge your logic
```

Do not immediately look for solutions.

### Recommended workflow

```text
Read Problem
     ↓
Understand Requirements
     ↓
Think About Logic
     ↓
Write Pseudocode
     ↓
Write Python Code
     ↓
Run Program
     ↓
Test Edge Cases
     ↓
Debug
     ↓
Improve Code
```

# 🧠 Problem-Solving Rules

For every problem:

- ✅ Understand the problem first
- ✅ Try solving it independently
- ✅ Write the logic before coding
- ✅ Test multiple inputs
- ✅ Check edge cases
- ✅ Debug your own errors
- ✅ Avoid copying solutions
- ✅ Rewrite difficult problems later
- ✅ Keep improving code quality

The objective is **not just to complete 15 files**.

The objective is to become capable of solving problems without depending on tutorials.
