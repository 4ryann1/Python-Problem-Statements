## 📌 About

This repository is a personal challenge to solve **1000 Python problems**, split across **100 topics**, with **10 problem statements per topic** — ranging from basic syntax to advanced data structures, algorithms, and applied mini-projects.

The goal is to build strong fundamentals through **consistent, structured, daily practice** rather than random problem-solving.

---

## 📂 Repository Structure

Each topic has its own folder containing 10 numbered solution files with problem statements as docstrings/comments.

```
1000-python-programs/
│
├── 01-basics-io/
│   ├── 01_hello_world.py
│   ├── 02_swap_two_numbers.py
│   ├── ...
│   └── 10_....py
│
├── 02-variables-datatypes/
│   ├── 01_....py
│   └── ...
│
├── ...
│
├── 100-mini-projects/
│   ├── 01_....py
│   └── ...
│
└── README.md
```

Each solution file follows this format:

```python
"""

<Problem statement in 1-2 lines>

Input: ...
Output: ...

    pass

    solve()
```

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/<your-username>/1000-python-programs.git
cd 1000-python-programs
```

Run any specific problem:

```bash
python 01-basics-io/01_hello_world.py
```

**Requirements:** Python 3.10+
Some topics (NumPy, Pandas, Matplotlib) require extra packages:

```bash
pip install -r requirements.txt
```
